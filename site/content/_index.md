---
title: Somad
description: SomaFM in your terminal. Playback that outlives the TUI.
features:
  - title: Music that outlives the TUI
    text: Playback runs in a background daemon. Quit the terminal UI and the music keeps playing; reopen it any time to pick the session back up.
  - title: Headless CLI
    text: play, next, pause, stop, status, volume and list work without opening the TUI, so they slot into scripts, keybindings and status bars.
  - title: Every SomaFM channel
    text: Browse and filter the full channel list, mark favorites, and jump straight back to your last-played channel on startup.
  - title: Live track info
    text: Artist and title arrive with the stream itself, so the TUI, the tray and media players always show what is playing.
  - title: Remote control
    text: Run the daemon on the machine wired to the speakers and control it from your laptop over TCP, with TLS and a pre-shared key.
  - title: Tray icon and media keys
    text: A menu-bar or tray icon with channel picker and playback controls, and MPRIS on Linux so media keys keep working with the TUI closed.
  - title: Resilient streaming
    text: Buffered playback with a stall watchdog and automatic reconnection, so a flaky network means a pause, not a restart.
  - title: Fast to start
    text: The channel catalog is cached and refreshed in the background, so the TUI opens instantly.
---
